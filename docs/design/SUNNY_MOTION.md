# 晴岛动效：设计与维护规范

日期：2026-10-21。方案：`shizhi.sunny-motion.v1`。基于已选定的晴岛原版，覆盖当前 main 基线的全部可用界面；不将其他分支或发布版的笔记、任务、番茄钟等能力带入当前代码。

用户选择：顺滑克制、正式软件接入、独立演示与交接。动效帮助理解变化和操作结果，保持阅读安静。参数是本项目建议，并非 Apple 官方参数。

- [离线交互演示](../../design-lab/2026-10-21-sunny-motion/index.html)：全部为示例数据，支持场景重置、主动作、半速与减少动态效果。
- [机器档案](../../design-lab/2026-10-21-sunny-motion/design.json)：覆盖清单、事件、参数、接入位置和减少动态效果行为。

## 统一语言

| 参数                  | 当前值                           | 用途                     |
| --------------------- | -------------------------------- | ------------------------ |
| `--motion-press`      | 100ms                            | 可用按钮按下             |
| `--motion-release`    | 160ms                            | 释放、颜色、进度值过渡   |
| `--motion-feedback`   | 180ms                            | 状态与结果淡入           |
| `--motion-page`       | 240ms                            | 页面、分组内容、出处强调 |
| `--motion-month`      | 220ms                            | 月份日期区域             |
| `--motion-disclosure` | 200ms                            | 阅读目录、证据原文折叠   |
| `--motion-ease`       | `cubic-bezier(0.22, 1, 0.36, 1)` | 连贯减速，无明显回弹     |

入场最多移动 8px，分组延迟限制为 0–120ms。按钮缩放为 0.985，资料卡悬停上移 2px。计时数字、流式回答正文和植物插画不做重复装饰动画。出处强调用短暂浅绿内描边。

## 功能覆盖

| 场景                       | 触发与表现                                                                           | 中断及真实状态边界                                                      |
| -------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| 启动／失败／重试           | 新的加载、错误或页面节点出现时淡入                                                   | 不添加等待，重试直接执行 bootstrap                                      |
| 主导航／设置／返回         | 页面 240ms 淡入，按前进／返回方向移动 8px；导航胶囊承接选中按钮位置                  | 同页点击不重播；新导航替代旧动画；聊天不卸载                            |
| 首页／最近阅读             | 欢迎区、资料、月历依次轻入场；最近资料出现时淡入                                     | 真实空态、错误提示不改；时间轮询不重播首页                              |
| 切月／签到                 | 日期主体按方向移动；签到成功后按钮和今日日期反馈                                     | 导航按钮保持原位；签到结果来自原有接口                                  |
| 手动学习计时               | 开始／暂停状态淡入，颜色平滑变化                                                     | 秒数文本直接更新；轮询不触发状态动画                                    |
| 导入／取消／结果           | 准备、进度区域、完成或失败报告淡入                                                   | 进度文本更新不重播区域，文件对话框使用 Windows 系统行为                 |
| 搜索／格式筛选             | 输入即生效，结果区域短淡入；只有新挂载的卡片入场                                     | 不延迟查询，不重新创建全部已有卡片                                      |
| 阅读／返回                 | 阅读区淡入、标题栏按方向轻移，返回反向承接                                           | 不变换 PDF 画布、文字层坐标或正文滚动容器                               |
| 目录／护眼／翻页／复制     | 目录淡出并轻移，显示切换由浏览器处理；护眼颜色过渡；PDF 渲染完成后淡入；复制文字反馈 | 收起目录立即 inert／aria-hidden；关闭后才一次释放列宽，避免逐帧重绘 PDF |
| 出处跳转                   | Markdown 目标标题或 PDF 页短暂内描边                                                 | 仅在原有验证成功并到达目标后强调，不猜测来源                            |
| 会话／提问／生成／停止     | 会话切换淡入；问题入场；生成终止状态淡入                                             | 回答增量文本不触发整块动画，停止与切页不等待动画                        |
| 问答模式／范围／检索／重建 | 模式与范围变化时工具区域淡入；进度、取消和预览区域入场                               | 只显示真实检索结果；进度事件不反复入场                                  |
| 证据原文                   | 使用原生 details／summary，局部 200ms 展开与收起                                     | 保留键盘操作和原文；布局动画仅限该折叠区                                |
| 服务切换／检测／保存／密钥 | 服务配置区和成功、失败文字反馈淡入                                                   | 原有表单、密钥清理、确认和失败路径保留                                  |
| 模型下载／取消／就绪       | 下载动作状态切换；原生进度条平滑跟随实际值                                           | 不制造虚假进度；切页和动画不管理下载生命周期                            |

## 实现位置与维护规则

- `src/lib/motion.ts`：不依赖 React 的动画控制器，只观察新增的动效节点与明确声明的状态属性；不观察 characterData。`data-motion-key` 只绑定语义状态，不绑定秒数、下载进度或流式答案。
- `src/styles/motion.css`：所有通用时长、曲线、按钮反馈、导航胶囊、局部折叠与减少动态效果。由 renderer 入口最后加载，避免被旧过渡规则覆盖。
- `src/App.tsx`：控制器随应用壳挂载和清理；标记导航方向。各业务组件只声明表现层属性，保留原数据请求、effect、取消与保存逻辑。
- 控制器按元素替换进行中的 WAAPI 动画，完成后释放 fill；DOM 离开、聊天隐藏、系统偏好变化和应用卸载时取消残余动画。不使用等待动画结束后才执行业务的回调。
- `data-motion="page/month/reveal"` 为轻移入场；`fade/state` 为不改变几何的淡入；`highlight` 为出处强调。分组延迟通过 `data-motion-delay` 设置，方向可由元素的 `data-motion-direction` 覆盖外壳方向。
- 导航胶囊只测量一个选中按钮。阅读目录使用离散 display 过渡，避免整列宽度逐帧改变引起 PDF 连续重绘；证据原文使用 `::details-content` 局部高度过渡。其他业务页不做整体布局测量或翻转动画。

系统减少动态效果时，WAAPI 不启动，正在进行的动画取消，CSS 过渡与循环关闭，并取消按钮按下和卡片悬停的几何变化。保留文字、颜色、焦点和立即可用的操作。不要全局清空 transform，PDF.js 文字层依赖自己的变换。

## 演示与源码一致性

执行 `node scripts/build-motion-demo.mjs`，生成演示使用的经典脚本 IIFE 与 CSS 副本，源码 SHA-256 写入 `assets/sources.json`。双击 HTML 可用，不需要本地服务器，不加载远程字体、图片、模型或账号。

演示中的导入、聊天、下载等只模拟状态；真实软件的这些行为继续由原有业务接口驱动。半速开关仅用于本页预览，不进入正式设置或数据库。修改正式动效后重新生成副本并检查摘要一致；若演示场景或视觉行为改变，再更新对应录像。2026-10-22 为完整导航修正横纵定位，已同步生成副本；现存预览图／录像仍绑定2026-10-21的演示对象，当前软件验证见[整合交接](../testing/updates-integration-2026-10-22.md)。

参考 Apple 的 [连贯过渡](https://developer.apple.com/videos/play/wwdc2024/10145/)、[自然弹性](https://developer.apple.com/videos/play/wwdc2023/10158/)、[可中断响应](https://developer.apple.com/videos/play/wwdc2018/803/)，使用原生 CSS／WAAPI 实现适合桌面学习软件的轻量版本，没有复制 Apple 系统实现或设计资产。
