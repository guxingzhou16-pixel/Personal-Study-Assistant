设计日期：2026-10-22。设计 ID：`shizhi.sunny-navigation.v1`。在原晴岛配色、插画和动效基础上整理信息架构，依据用户确认的方案实施。

本轮以本地 `main` 的 `cfc2597` 为基线，保留当前已实现的学习能力。历史晴岛设计稿中的“规划中”不适用于当前功能。实现交接见[本次交接](../handoffs/2026-10-22-sunny-navigation.md)，[离线布局预览](../../design-lab/2026-10-22-sunny-navigation/index.html)及[设计 JSON](../../design-lab/2026-10-22-sunny-navigation/design.json)使用示例数据。

## 摘要与状态

- 路线使用 `listLearningDrafts()`，按 `createdAt` 取最近记录，显示目标、预算分钟、真实状态和记录时间。预算不是实际学习时间，完成态只称“草稿已保存”。
- 笔记使用 `listNotes()`，按 `updatedAt` 取最近记录，显示标题、关联资料、更新时间与笔记总数；不显示未保存草稿作为已保存内容。
- 摘要下面始终提供「查看完整学习路线／学习笔记」链接。有记录时定位对应记录，无记录时打开现有功能；不自动生成或保存。
- 长标题最多显示两行，完整内容通过下方详情链接查看；控件标签与错误提示允许换行。
- 初始读取显示加载文字；空库明确提示「还没有学习路线／学习笔记」。读取失败显示错误与重试，两个来源独立报告，失败不变成零记录。
- 进入首页、窗口恢复焦点或恢复可见时重新读取；路线结束或停止后通过已有事件刷新真实状态，流式片段不触发读取，无新增轮询。备份非空闲期间暂停；离页、重新读取和进入备份使旧结果失效。
- 第一次使用引导采用原生 `details/summary`，默认收起；不依赖模型配置，不增加设置项。展开仅在本次首页挂载内保留，返回首页重新默认收起。

## 组件与维护边界

`App` 继续管理页面与来源返回路径。新增 `home/HomeLearningSummary` 与 `settings/LearningTools`；原 `HomeStudyFlow` 及其专属样式移除。`NotesPage.presetNote` 为内部 `{ id, sequence }` 定位参数，走现有读取和脏稿确认；打开同一份正在编辑的笔记不重载草稿。路线复用已有 `presetTurn`。

组件仍使用 `desktop.ts`；IPC、共享桌面类型、主进程、数据库与模型协议均未更改。聊天、路线、笔记、复习和专注保留原常驻／隐藏策略，阅读侧栏与引用返回继续沿用原回调。设置页面仍按现有方式挂载，离开后未保存设置表单不新增恢复能力。

普通页面与二级路径沿用已有页面动效；首页摘要只在挂载时轻入场，不为状态读取增加循环动画。原生折叠、焦点和系统减少动态效果继续生效；不增加动画库或业务等待。

桌面维持一行顶部导航；560px 及以下把导航放在品牌下方，保留头像和齿轮，支持高缩放下键盘操作。颜色、字体与原晴岛 token 一致；设置工具卡片使用两列，小屏单列，标题和说明允许换行。

## 设计资产与验证

独立预览可切换空记录／示例记录、打开详情及设置工具，全部标注示例；不加载网络字体、远程图片或桌面桥接。预览 SVG 是原项目插画的本地快照，正式界面继续引用原资产。
