# 使用指南

本页描述当前维护源码的主要操作；公开安装包与维护源码的差异见[项目状态](../README.md#功能实现与验收状态)。本地体验可双击根目录 `打开拾知（本地最新版）.cmd`，代码更新后先关闭旧窗口再打开。

## 第一次使用

1. 在首页使用引导导入项目原创学习示例，先阅读一小段。
2. 在设置选择本地 Ollama 或兼容 OpenAI 的接口，填写地址与模型并保存。本地模型需先启动服务。
3. 分别检查模型列表、实际生成、嵌入文件与实际推理。列表检测成功只说明连接和列表可用。
4. 回到示例，准备第一次资料提问，先检查原文预览，再决定发送。

模型暂不可用时，仍可阅读、手写笔记、安排任务。语义模型是独立的固定 BGE 下载；缺少模型时保留关键词检索，不要求聊天必须使用 Ollama。

## 导入和阅读

- 资料库支持 PDF（50 MB 内）与 UTF-8 Markdown（5 MB 内），每次最多 20 份；原文件保留，本机副本按内容去重。
- PDF 支持原页、可选文字、目录／页码、缩放；Markdown 按标题阅读。位置与护眼选择保存到本机。
- 选中同页或同章节原文后，可复制引用、提问选文或加入笔记草稿。选文提问限 800 字，过长时缩小选区。
- 问答和笔记侧栏可往返；有效引用能回到保存的实际位置，再返回原页面继续。

扫描页和无法提取文字的页不能提供完整检索证据；当前不做 OCR。原文、引句与引用位置需要实际核对。

## 聊天、资料问答和练习

在“学习助手”选择问答方式：

| 方式             | 如何使用                                               |
| ---------------- | ------------------------------------------------------ |
| 普通聊天         | 直接输入问题；不会自动读取资料库                       |
| 资料问答         | 写清具体概念、选择范围，先“检索原文”，再核对证据后发送 |
| 知识卡片／短测验 | 输入资料中的概念，预览证据后生成三项练习               |

远程请求须明确同意实际发送内容和服务地址。生成可停止，已保存的部分会保留；请求计时不代表模型内部进度。引用编号有效不等于每个结论都有充分依据。

## 笔记、作答与复习

- 学习笔记保存“我的理解／原文依据／待解问题／下一步练习”；手写内容不会自动成为受验证引用。
- 阅读选文可带入草稿，核对并点击保存后才写入。已保存笔记可以预览资料依据并请求 AI 反馈。
- 短测验可逐题填写回答、疑问和手动复习日期。选择保存才进入本机与备份，不评分，也不把作答发送给模型。
- 轻量复习先尝试回忆，再按需查看上次作答、参考答案和出处。保存会替换该题上一份作答。
- 跨入口更新造成版本冲突时，保留当前输入、读取最新内容，核对后明确选择如何继续；不要把保存失败当成已写入。

笔记、作答和反馈可以按各自入口导出 Markdown。导出只包含已保存内容，不替代完整备份。

## 学习路线和长期记忆

1. 填写学习目标、检索概念、资料范围和 10～180 分钟预算。
2. 可手选最多五条允许当前模型使用的记忆，默认不选；先预览完整请求和原文。
3. 起草一次路线，核对步骤、时间、预期作品和实际引用。结构不合格时保留原始输出，不自动调整或重试。
4. 如需安排任务，选择步骤、日期与项目，点击“预览所选步骤任务”，再核对最终写入内容并确认。

路线只是建议，不自动执行命令、完成任务或写记忆。记忆页可以手动查看和编辑；默认仅用于本机模型的学习路线，使用时仍需手动选择。学习意向和用户自述不代表知识掌握。

## 任务、专注与日历

- 学习计划中创建项目和指定日期任务；任务预计分钟用于安排，手动标记完成是独立操作。
- 从任务进入专注，核对保存版本和本轮分钟后明确开始；可以暂停、继续或提前结束。
- 专注结束后手动保存复盘；“学会了什么／还卡在哪里”可以带入笔记或下一项任务的编辑器，核对保存后才写入。
- 专注计时、首页累计计时、签到和任务完成分开记录，不自动叠加，也不作为掌握证明。
- 睡眠、退出和长时间中断会结束本轮，不补计缺失时间；重启不会自动继续计时。

## 备份与恢复

1. 先保存需要保留的输入，暂停首页计时，结束当前专注，并完成或取消导入、生成、检索及模型下载。
2. 设置中选择“导出完整备份”，选择可信文件夹。成功后保留整个 `拾知备份-.../`，不要只复制其中一个数据库。
3. 恢复时选择包含 `manifest.json` 的备份目录，等待校验并核对数量预览。
4. 确认整份替换并重启才应用恢复；放弃预览不更换学习数据。

备份仅含已保存内容，未加密，不包含密钥、模型和派生索引。恢复保留原学习目录，不合并记录。若校验或启动切换失败，保留原文件和错误信息，不自行清空数据目录或伪造数据库版本。

路径与恢复机制见[数据地图](CODEMAPS/data.md)。原详细操作和历史回退记录保留在[整理前 README](archive/README-history-2026-10-21.md#完整学习数据备份与恢复)，其中旧版本范围按原文日期解释。

## 保存与主题

设置保存后应用主题、昵称、目标和回应风格；界面主题与阅读护眼、模型回应风格分别选择。笔记、任务、复习和路线编辑等未保存输入只存在于窗口内，关闭或重载前应先处理；正常笔记退出有专用草稿确认。

## 版本信息与手动更新

在“设置 → 软件更新”查看当前版本、发布说明和上次成功检查时间。打开设置时会向项目的固定 GitHub 发布接口匿名检查最近最多 30 条记录，包含预览版；成功结果在本次运行中缓存 5 分钟。“检查更新”会重新请求，失败会显示原因，不会把网络失败显示成已经是最新版。检查不发送学习资料或模型密钥。

发现更高的安装包版本后，点击“升级最新版”在浏览器打开已核对的官方发布页；“查看发布记录”始终打开[项目的 GitHub Releases](https://github.com/guxingzhou16-pixel/Personal-Study-Assistant/releases)。下载 Windows x64 NSIS 安装包后，保存内容、关闭拾知，再运行安装程序。当前发行包未签名，Windows 可能显示提示；应用内不会自动下载、运行安装程序。

版本判断使用安装包文件名中的实际应用版本，不把发布标签改名当成升级。首个 `v0.1.1-preview.1` 标签对应的安装包实际为 `0.1.1`；本地开发运行若版本相同，只显示“版本号与发行版相同”，源码可能仍含未发布修改。当前维护源码的入口不会自动出现在已下载的旧安装包中。
