## 3. P0：项目 CRUD、归档与关联

- [ ] 新建请求 `id=null, revision=0`，返回主进程生成的 UUID、revision=1、createdAt/updatedAt；标题单行非空，标题 120/goal 2000 字符边界与超限分别验证。
- [ ] 编辑保留 ID/createdAt，返回新版本与更新时间；旧 revision 保存被拒绝，不覆盖当前数据，界面保留编辑稿。非法 UUID、负数/浮点/非安全整数版本、错误类型、NUL、标题换行和额外字段均拒绝。
- [ ] 项目上限 200 包含已归档项目。达到上限不增加记录、不删除旧项目；已有项目仍能编辑、归档和恢复。
- [ ] 归档/恢复仅改变项目及自身版本，保留所有既有任务内容、日期、状态、完成时刻和任务 revision；归档不自动完成项目或任务。
- [ ] 已归档项目仍在 overview 中并清楚标记。不能新建任务关联归档项目，也不能把其他项目/独立任务改关联到归档项目；绕过前端直接调用 IPC 仍拒绝。
- [ ] 原本关联已归档项目的任务允许编辑详情、改期、完成、重开和解除关联；保留同一归档关联的普通编辑可保存，不意外拒绝历史任务。改关联到未归档项目可保存。
- [ ] 项目恢复后可再次新建/关联任务；不存在的项目引用明确报错，无部分写入。
- [ ] 本阶段无删除项目 API 或界面动作；归档不是删除，不宣称已释放项目数量上限或删除其任务。

## 4. P0：任务保存、限额与日期

- [ ] 新任务使用 `id=null, revision=0`，生成 UUID/revision=1、真实时间，状态 todo、completedAt=NULL；可关联未归档项目或保持 projectId=NULL。
- [ ] 标题单行非空且最多 120、details 最多 4000，预计 minutes 为整数 5～480；边界值通过，一个单位超限、空标题、NUL、错误类型、浮点/NaN/Infinity 均拒绝。说明文字换行可保存并正确展示。
- [ ] 保存请求只接受受限草稿字段，不接 status、completedAt、createdAt、updatedAt、角色/工具、SQL、路径或伪造来源；非法 UUID/projectId/revision 拒绝。
- [ ] 全库上限 5000 包含所有日期及完成任务；上限后新建报错且不覆盖旧任务，已有任务仍可编辑、完成、重开和删除。overview 不把当前日数量当作全库数量。
- [ ] 日期必须规范 `YYYY-MM-DD`，真实年份 0001～9999；测试 0001-01-01、0099-12-31、0100-01-01、9999-12-31，不能被 JS Date 的 0～99 年特殊行为改变。
- [ ] 闰年 2000-02-29、2024-02-29 有效；1900-02-29、2100-02-29、2025-02-29 无效。拒绝 0000 年、10000 年、月份 00/13、日期 00、4 月31日、非补零/空白前后/时间或时区后缀等非规范值。
- [ ] 安排日期在正负时区均按原字符串保存/查询，不经 UTC 字符串解析而偏移一天；跨年、月底和系统夏令时不改变任务安排日期。
- [ ] 原生日期控件在 Windows 可选择/输入有效日期，清空或无效输入有可理解的提示；产品按钮和输入范围与运行时范围一致，不把 picker 返回空值保存为今天。
- [ ] 编辑保留 ID/createdAt，增加 revision，保留原 status/completedAt。已完成任务改日期/项目/内容后仍完成、完成时刻不变；改期保存成功切换到保存日期查看，旧日移出、新日出现，没有复制品；后续刷新/继续编辑正常。
- [ ] overview 返回明确的请求 day、所有项目和仅该日任务，顺序稳定；缺少当前日任务显示空态，不把其他日期任务混入。指定日期非法时拒绝，不能偷偷查询今天。
