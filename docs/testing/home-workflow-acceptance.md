## 二、日期、刷新与迟到响应

- [ ] 从计划/路线/专注回首页重新读取，实际任务编辑/改期/完成/重新打开/删除及已确认提议反映最新保存记录；新生成不自动开始或写入任务。
- [ ] 显式刷新、窗口重新获得焦点或页面恢复可见会重读；每30秒只核对本机日期，日期不变时不会定时查询数据库。失焦/隐藏时不为轮询日期持续写数据。
- [ ] 保持首页跨本地午夜、睡眠后隔日恢复、系统日历日期前移/后移，日期和列表切换正确，旧日期快照不当今日数据。
- [ ] 请求等待中跨日，无论旧成功或旧失败都不覆盖新日期；离首页/卸载、换日、再次刷新或备份暂停后旧Promise不能覆盖后来的结果，旧finally不改变当前请求loading。
- [ ] 点击任务时再次核对当前日期；午夜附近未刷新列表不会直接打开/准备昨天任务，会先刷新今日。查看全部用点击时的本地日期。
- [ ] 备份状态非idle时暂停首页读取并隐藏旧任务操作；返回idle重新读。备份期间晚到结果不复活， maintenance锁不放宽；备份状态晚到/失败也不误执行任务写入。
- [ ] 事件监听和日期定时器卸载清理，重复进出首页与React开发严格模式不叠加监听/无限查询，后台回包失败可恢复，不造成未处理Promise拒绝。
