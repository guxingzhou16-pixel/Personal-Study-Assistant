- [ ] v10 升级前生成 `before-v11-UUID.sqlite3` 一致性备份，可只读打开且仍为 v10。重复打开不再次迁移、不重复恢复已结束记录。
- [ ] 真实 v1～v9 结构跨版本升级至 v11；每次备份按旧版本+1命名一次，所有历史数据/外键/快照保留。旧结构不得含后来新增的表/列/索引。
- [ ] 备份失败不升级；DDL/迁移失败整事务回滚，不产生半张表或提前更新版本。拒绝 v12+、损坏结构或不合法记录，不自动重置/删除数据库。
- [ ] 一次最多一条 running/paused，SQL 部分唯一索引与服务检查一致；终止记录不占活动槽位。总数 10000 时明确拒绝新增且不删除历史，最近列表最多 20 条终止记录。
- [ ] 恢复时 running/paused 全部成为 interrupted/app-restart，保留最后已保存 elapsed、任务快照与复盘；不补算关机时段、不续计、不自动完成。恢复写入失败应明确启动失败。
- [ ] UUID、任务来源版本/标题/日期、预算、elapsed、状态/原因/endedAt 组合、revision、时间、复盘恢复校验；伪造负数/NaN/小数/超限/不合法状态不能当正常数据展示。
- [ ] 删除、编辑、改期、归档项目、手动完成或重新打开任务，不删除/改写旧专注快照；来源标识不是级联外键。任务不存在或已改期时查看入口明确说明，不能展示虚构当前任务。

## 3. P0：输入、权限与开始

- [ ] 只有实际已保存 todo 任务可开始，开始时匹配 taskId/taskRevision；已删除、手动完成或版本改变拒绝，不能沿用旧任务选项开始。
- [ ] 默认 25 分钟，整数边界 5/120 可接受，4/121/小数/字符串/Infinity/NaN 拒绝；预计任务分钟不自动当成实际专注分钟。
- [ ] 未知字段、伪造标题/任务快照/elapsed/时间/状态/原因/SQL/路径/工具均拒绝。非主窗口或非主 frame 不能调用 IPC，沙箱与上下文隔离不变。
- [ ] 开始成功保存真实任务 ID/revision/标题/安排日期、真实开始时刻与 UUID，再显示专注；重复点击/两个并发开始不能创建两条活动记录。
- [ ] 活动 paused 仍阻止新开始；拒绝、选择任务、切页或预览不自动开始，不自动修改任务、记忆、签到、首页累计时间。
- [ ] 开始请求应答丢失时界面保留不确定状态、阻止再次写入，明确读取实际记录后再决定下一步；自动轮询不当成重发授权。

## 4. P0：真实计时与中断边界

- [ ] 主进程使用单调时钟，每秒落盘；renderer 不上报 elapsed，也不靠界面倒数到零写 completed。连续读取 overview 不重复计时。
- [ ] 正常短心跳跨过目标才计满，elapsed 上限为预算毫秒，completed/elapsed/结束时刻一次保存；不超过目标、不重复完成、不自动开启下一轮或休息轮。
- [ ] pause 结算可靠短尾段并停止；暂停期间不增加时间，resume 从新单调基点继续同一条记录。重复/陈旧控制请求、未知 action、无效 UUID/revision 明确拒绝或按已记录的幂等契约处理。
- [ ] 普通 elapsed 检查点不增加控制 revision；暂停/继续/提前结束/计满/中断/复盘才递增。计满与控制竞争不得复活终止记录或覆盖复盘。
- [ ] 心跳恰好 30000ms 与超过 30000ms 的边界；超过时直接 interrupted/heartbeat-gap，缺失区间不计入，即使它跨过目标也不能 completed。
- [ ] 系统 suspend、实际主 frame 重载、renderer 崩溃、最终退出分别中断；只保留最后落盘时间，尾段可能丢失约一秒。系统恢复/重启不自动继续。
- [ ] 普通 React 切页、PDF 子 frame、hash 导航、最小化不误中断；点击关闭后取消笔记退出确认，专注仍继续；真正退出才中断。
- [ ] paused 时睡眠/退出/重载也终止为 interrupted；提前结束为 stopped/user-stop，保留实际 elapsed，不伪装计满。终止后 resume/pause/stop 不改写历史。
- [ ] 修改系统时间前后倒数依然只依据单调时钟；跨本地午夜不改变任务安排日期，签到只针对操作当日，不补签来源日期。
- [ ] 累计学习计时与番茄钟同时开启时分别记录，显示不相加；任一保存错误不会跳过另一条心跳，不把番茄记录灌入 study_days。
- [ ] 保存/事务/提交失败立即冻结到最后已确认 elapsed，后续先重试写 interrupted/storage-error；失败继续明确报错、禁止开始新轮。成功恢复后显示真实中断，不自动续计/补算/完成。

## 5. P1：复盘与独立行为

- [ ] 计满/提前结束/中断均能写简短复盘；最多 1000 字符，边界、NUL、未知字段/无效 revision 校验。running/paused 不能提前写终止复盘。
- [ ] 保存复盘只改变所选终止记录的 review/revision/updatedAt，保留 elapsed/来源/状态/开始结束时刻；同内容保存行为按实际契约核对。冲突不覆盖新版本、不丢草稿。
- [ ] 选另一条记录时脏复盘先放弃确认；取消继续编辑。页面导航保留复盘，关闭/重载未保存内容可能丢失，界面不冒称自动保存。
- [ ] 按ID受限读取正确返回实际FocusSession，非法/缺失ID明确拒绝；复盘返回FocusReviewResult的实际保存记录与overview，不以最近列表推断写入成功。脏稿钉住的记录滑出最近20条后，写入应答丢失仍能明确重新读取旧ID核对；保留稿与原revision、重新载入要确认，不自动重绑定/覆盖新复盘。
- [ ] 最近 20 条刷新/new completion 不覆盖正在编辑的旧记录或脏稿；保存失败/应答异常后先读取核对，不能以空稿或新版本静默覆盖。
- [ ] 单独点击“今日签到”仅调用今天的真实签到，重复签到不增加记录/时长；没有自动任务完成、复盘保存或补签。失败不显示已签到。
- [ ] 查看任务经过原计划页的脏稿确认并读实际记录；任务完成只在原计划页由用户单独点击，不以专注计满推断任务完成或知识掌握。
