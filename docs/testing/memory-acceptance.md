## 3. P0：记忆 CRUD 与来源边界

- [ ] 手动创建初始 `id=null, revision=0`，主进程生成 UUID、来源 `manual`、时间与 revision=1；保存不请求模型。
- [ ] 标题单行 100 字符、内容 1000 字符、两者非空，拒绝 NUL/错误类型/越界、非法 UUID/revision/kind/scope；允许正文换行。边界值及一个字符超限分别验证。
- [ ] 新建最多 500 条；达到上限明确报错且不增加记录、不删除旧记录；已有条目仍可编辑/删除。
- [ ] 编辑保留 ID/createdAt/来源，revision 增加；来源不能通过 `origin`、`originTurnId` 等额外字段伪造或更改。
- [ ] 乐观更新与删除冲突拒绝覆盖/删除，界面保留编辑稿并提供重新加载或另存手动记忆；旧版本删除失败不冒充成功。
- [ ] 非法/损坏数据库记录的时间、来源、内容、使用范围及学习快照显式报错，不返回假空列表或重置数据。
- [ ] 删除实际移除当前记忆，后续列表/选择不能使用；历史路线快照与升级备份仍存在，产品说明与行为一致。

## 4. P0：提议与显式确认

- [ ] 只接受已保存、`completed`、有学习请求、有证据且有答案的学习路线；普通问答、笔记反馈、空证据说明、streaming/stopped/error/interrupted 均拒绝。
- [ ] 默认提议取主进程保存的 goal，类别学习记录、范围 local、标题“待学习”；不复制模型回答，不推断已完成/掌握，不产生额外模型请求。
- [ ] prepare 只产生内存预览；未确认前 DB 无新记忆。编辑只允许标题/内容/scope，最终预览内容来自主进程校验，不接受工具、来源、提示、任意正文快照或路径字段。
- [ ] 编辑后旧确认按钮失效；重新准备同一来源路线使旧 proposal UUID 失效；确认只收新 UUID，不接 renderer 自造最终内容或来源。
- [ ] 确认时重新核对来源路线版本/状态，返回实际 StudyMemory；记录来源 learning-route 与真实 turn ID，显示提议与实际写入结果。
- [ ] 10 份预览/10 分钟有效期；过期、被淘汰、拒绝、已确认 ID 再确认均不写；重复点击/并发确认最多保存一次。
- [ ] 拒绝、取消、切换路线、隐藏页面只撤销预览；合法 UUID 的 discard 可重复，无数据变化。异步 prepare 晚到 ID 应立即清理，不复活旧提议。
- [ ] 写入失败（磁盘/权限/上限）不显示成功，保留编辑内容；无记录部分写入。确认请求已经提交后切页仍可能保存成功，不能把切页描述为撤销已发确认。
- [ ] 恶意资料/模型文本提出保存记忆、修改进度、运行命令均不会触发接口；只有用户明确操作进入提议确认。

## 5. P0：使用范围与隐私

- [ ] 默认不选择任何记忆；路线每次手动选最多 5 条且不可重复；disabled 不可使用，local 只用于 hostname 为 localhost/127.0.0.1/[::1] 的服务，remote 可用于本机及远程。
- [ ] 全库与单资料路线只读取本次选中的记忆，普通聊天、RAG 问答、笔记反馈完全不读取记忆；无自动整库扫描或隐藏追加。
- [ ] 检索开始前、检索完成后及发送前核对每条 ID、revision、内容和当前 scope；删除/编辑/禁用/改变范围后旧预览不能发出请求。
- [ ] 预览绑定主进程实际 provider/baseUrl/model；检索期间或准备后切换模型/地址必须重新准备。即使 renderer 传新的 expectedProfile/consentEndpoint，旧本机预览也不能带 local 记忆发往远程。
- [ ] 远程 checkbox 明确包含目标/预算/检索词/片段/所选记忆及目标地址/模型；选项、输入、模型或预览变化后旧同意失效。
- [ ] 实际 payload 仅含本次 goal/query/minutes、真实证据和所选记忆 title/content/kind，无整库、路径、凭据、旧路线/旧反馈/日历及未选记忆。
- [ ] 记忆作为用户偏好/自述数据，无引用编号，不作为知识事实或系统指令；恶意记忆不改变工具权限、引用范围或确认要求。
- [ ] 空证据不读取密钥、不发请求，即使选了记忆；历史只表示本次选择快照，不能声称必然已发送。
- [ ] 删除不可能撤回已发给模型的数据，也不移除旧回答/快照/备份；删除后新请求及旧未发送缓存不得再使用。不复用历史快照绕过删除。
