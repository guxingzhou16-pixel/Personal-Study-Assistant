# 会话与学习路线历史管理：独立验收清单

## 范围与当前状态

本轮实现普通/资料问答会话的标题搜索、重命名、删除、Markdown 导出，以及单份学习路线删除/导出。**2026-10-08 已执行独立源码验收，范围和剩余条件见末尾执行记录。** 主线仅类型检查、生产构建、源码格式/diff 与静态审查；测试对话补充必要的行为测试，不引用以前通过的数量作为本轮结果。

当前主库 v12、活动库 v1、派生索引 v2、完整备份 format1。历史管理自身无迁移或新依赖；v12 练习轮次也纳入普通会话管理，迁移及严格 12/1 备份政策参阅 [练习清单](practice-acceptance.md)。保留现有聊天/资料问答/反馈/路线/提议的失败案例及测试断言；不要为通过而移除权限或迟到更新检查。

开发版使用全新临时学习目录、合成资料、模拟接口和假密钥，避免访问个人数据。正式包忽略开发数据目录覆盖，安装/启动须用独立 Windows 用户或可恢复 VM，沿用 [安装验收](packaging-acceptance.md)。固定候选471e0a73已包含历史管理；10-08只读核对包来源和摘要，正式包运行仍未执行。后续生产修复须新提交/新UUID候选，不覆盖旧包。

## 一、数据与接口权限

- [ ] 原有 v12 数据直接打开，schema/全部旧记录保持；不会重复迁移或重建表。v11→v12 新增 practice_request 与升级前备份另按练习清单验，旧历史不改写。
- [ ] 四个新增桥接为 `previewHistory(target)`、`renameConversation(id, version, title)`、`deleteHistory(target, version)`、`exportHistory(target, version)`；preload 解包后的成功值/错误契约正确，旧桥接方法列表断言由测试方同步。
- [ ] `target` 只接受 `{ kind: 'conversation' | 'learning', id: UUID }`；拒绝空值、数组、非字符串/畸形 UUID、不支持 kind、多余字段，以及损坏/缺失记录，不访问路径或 SQL。
- [ ] version 只接受 64 位小写 SHA-256；伪造值/旧值拒绝，失败不写入。散列用于确切内容比较，不是用户授权或备份真实性证明。
- [ ] conversation 接口只接普通、资料问答与练习的 purpose=chat；猜测笔记反馈或 learning-agent 会话 ID，读取管理预览/改名/删除/导出均拒绝。
- [ ] learning 接口只接具有 learningRequest 的 learning-agent 轮次；普通问答、笔记反馈、错误用途/快照均拒绝，不借 getTurn 绕过用途隔离。
- [ ] 目标记录有 streaming 状态，或目标仍是 ChatService 活动记录时，管理/导出拒绝；先停止后才允许。其他记录正在生成时可管理已有终止历史，不停止那次生成。

## 二、会话搜索与标题

- [ ] 标题搜索只过滤列表，不查资料、正文或调用模型；大小写/前后空格、中文、无匹配、清空搜索、长标题正确，不改变当前打开的会话或原顺序。
- [ ] 刷新返回实际保存列表；迟到旧列表不能覆盖较新刷新或把本机已删除会话带回。
- [ ] 改名预先读取保存记录，显示当前标题；1～120 字符单行标题保存，前后空白按约定修剪；空白、超长、换行/控制字符拒绝。
- [ ] 保存成功才更新列表与打开会话标题/更新时间；取消或存储失败保留原记录，失败保留输入，不显示虚假成功。
- [ ] 空会话先自定义标题再发第一问，主库与界面均保留自定义标题；默认“新会话”仍在第一问自动命名。将标题手动改成默认文本“新会话”时，第一问仍可自动命名，这是无额外命名标记的当前边界。
- [ ] 重启后标题保留，重命名不改回答、证据、普通上下文或来源；新轮次不覆盖自定义标题。
- [ ] 改名编辑期间发新问/生成结束或记录有其他变化后，旧 version 保存被拒绝；“重新核对记录”读取新版本并保留输入，展示新保存标题，再次明确保存才能覆盖。
- [ ] 未保存标题随切换会话/重载丢弃，不自动保存，不与笔记或计划脏稿混用；检索输入与问题草稿不被改名/删除操作默认覆盖。

## 三、会话删除

- [ ] 原生警告显示真实保存标题和问答数量；包括普通/资料问答混合、空会话、停止/错误/中断轮次；默认/取消/Esc/关闭对话框均保留记录。
- [ ] 明确确认后只删除目标 conversation 及其 chat_turns（含证据）；不删除资料副本/索引/阅读位置/笔记/反馈/路线/记忆/项目/任务/专注/签到或计时。
- [ ] 删除无回收站；旧备份/导出/远程已发数据不撤回。确认文案如实说明，不把删除说成“彻底擦除”。
- [ ] 确认期间修改记录、开始目标生成、目标已删除等冲突：最终重新校验并拒绝，不误删另一记录；相关生成入口在历史原生对话框/导出期间由主进程拒绝。
- [ ] 重复点击/并发确认/重放旧请求，不误删别的记录、不生成空会话、不自动再请求模型；删除最后一会话后显示空状态，下一问才按原行为创建新会话。
- [ ] 删除成功后，迟到 get/list/chat-update 不复活记录或旧回答；关闭/重载/重新打开应用仍已删除。切页后的成功结果仍更新父页面真实列表。
- [ ] 磁盘/SQL 写入失败不能先把记录从界面移除；应答丢失时先刷新核对实际记录，不自动重发或当作取消；刷新错误与写入错误分别记录。
- [ ] 500 会话上限包括专用会话；删除一个普通会话确实释放容量，不能删除反馈/整个路线会话来绕过用途边界。

## 四、单份学习路线删除与来源

- [ ] 正常/空证据本地说明/停止/错误/中断的保存草稿均可删除；正在生成的目标拒绝，删除其他历史不停止当前路线。
- [ ] 原生警告展示保存目标与单份数量、任务/记忆保留但来源入口不可再打开、未确认提议失效；默认取消不写。
- [ ] 确认只删所选轮次，单例 learning-agent 会话及其他草稿保留；删除后可继续起草，100 份上限释放一个位置。
- [ ] 删除最新/最旧/最后一份草稿，列表及选中项正确；迟到 list/update 和 seenDrafts 合并不复活已删除 ID；刷新正常选择一份存在的草稿或显示空态。
- [ ] 从任务来源打开已删路线明确报告缺失，任务标题/状态/项目/预计分钟/完成时刻/来源 UUID 与 revision 不改；focus 原任务快照也保留。
- [ ] 已确认的记忆仍保留内容/scope/来源 UUID；其他路线的历史记忆快照不变，不把删除解释成撤回远程数据。
- [ ] 删除前已准备的任务/记忆提议，删除后确认因缺失来源拒绝，无新增任务/记忆；未选中的缓存也由主进程复核，不能只靠组件卸载。
- [ ] 提议确认先成功、随后删除来源：已经真实保存的任务/记忆保留；删除先成功、随后确认：拒绝写入。执行顺序明确，隐藏界面不等于撤销已发确认。
- [ ] 来源引用和旧入口指向已删轮次时报错，不猜位置；资料本体仍能独立阅读，别的轮次证据可正常打开。

## 五、Markdown 导出与文件保护

- [ ] 原生保存选择可取消；文件名处理 Windows 非法字符、保留设备名、结尾点/空格和 Unicode，不向 renderer 回传绝对路径。
- [ ] 文件只为 `.md`，需要覆盖时系统明确提示；禁止应用数据根目录及其全部后代（包括恢复后的活动目录），通过目录链接指向数据目录也拒绝。
- [ ] 导出是 UTF-8 已保存快照，不含未发送问题/未保存标题/未确认提议，不读取密钥/密文、其他记忆、整个资料库或当前模型状态。
- [ ] 问答顺序、问题/部分答案/状态/notice、provider/baseUrl/model/时间/轮次版本真实；空会话有元信息，空答案不伪造完整回答。
- [ ] 路线保留当时目标/检索词/来源 ID/预算，以及选择的全部记忆快照；当前记忆后来被修改/停用/删除也不替换历史；空证据说明未调用模型。
- [ ] 保存证据逐项保留编号/资料名/格式/标题/锚点/页码或标题行号/UTF-16 起止/确切原文，不把当前资料内容补进旧快照，不依赖当前源文件才能导出。
- [ ] 恶意 HTML/远程图片/外链/反引号围栏放进足够长的字面文本块，不在普通 Markdown 阅读器中加载为活动内容；多个连续反引号/换行不会逃出原文块。
- [ ] 导出说明文件未加密、包含私人原文及记忆、不提供应用内跳转、不用于恢复、不证明回答正确；没有写入应用的 API key 或密文（用户/模型正文自己写的秘密属于正文）。
- [ ] 选择位置后及暂存完成后重新校验记录；中途变更/删除/生成拒绝，原目标保持。历史操作锁与笔记导出互斥，失败/取消释放锁，不永久禁用发送。
- [ ] 写入失败/文件占用/目录权限/磁盘不足不报成功，暂存文件尽力清理；失败后旧目标内容不被半文件覆盖。正常覆盖后实际文件内容与保存快照一致。
- [ ] 既有笔记 filename/writeNoteExport 包装抽取后行为、错误代码/文案、目录保护、取消和已有导出流程无回归。
