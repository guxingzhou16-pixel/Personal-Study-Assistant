# Agent 任务提议与确认写入：独立验收清单

日期：2026-10-05。对应v10引入的任务来源/提议，当前主库v12、从已保存学习路线安排一项每日任务的受控流程。

**状态：实现待验收，以下项目均未执行。** 主线对话负责实现、类型/生产构建、修改文件格式与静态审查；测试对话补充并执行功能规格。本文件是交接清单，不是已通过的测试报告。一次提议只新增一项待完成任务，不自动拆分路线、不修改已有进度、不推断学习完成或掌握程度。

v12 练习迁移及校验见 [练习清单](practice-acceptance.md)；构造 v11 及更低夹具须去掉 `practice_request` 列/约束，不只降低版本。完整备份当前只支持 12/1，旧 11/1 文件夹由对应旧版在隔离环境恢复后再升级。

## 1. 隔离环境与规格准备

- 使用临时目录及人工生成资料/数据库，通过 `STUDY_COMPANION_DATA_DIR` 隔离真实 Electron；不打开、改写、清空或复制进仓库 `%APPDATA%\StudyCompanion`。
- 本功能的起草、编辑、预览、确认、拒绝和查看来源不需要模型请求、密钥、检索、联网下载或付费 API。可用人工生成的保存路线测试提议；验证真实路线入口时使用本机模拟服务和假密钥。
- 先读 `electron/core/storage.test.ts`、`document-storage.test.ts`、`chat.test.ts`、`rag.test.ts` 及 `tests/desktop.spec.ts`；历史 schema 断言和桥接清单需要按真实变更核对，不直接沿用历史通过数量。
- 建议补充 `electron/core/task-proposals.test.ts`、`planning-storage.test.ts` 中提议创建与来源保留规格，以及 `tests/task-proposal.spec.ts`。本轮没有创建或执行这些功能测试，测试方实际增加规格后再选择命令。
- 原有笔记、AI 反馈、学习路线、记忆和手动项目/任务仍有独立待验收项，见 README、`memory-acceptance.md`、`planning-acceptance.md`。历史清单中的版本门限须对应其验收提交；当前主库以 v12 为准，本清单不替代之前的功能验收。

v11 引入的专注表/迁移/计时中断另参阅 `focus-acceptance.md`；构造v10及更低版本夹具时必须去掉focus_sessions及相关索引，保留真实结构。

## 3. P0：来源资格与可编辑草案

- [ ] 只有真实保存于 `learning-agent` 用途会话、带 `learningRequest`、状态 completed、有证据且有非空回答的轮次可起草。普通聊天/资料问答、笔记反馈、streaming/stopped/error/interrupted、空证据说明和空白回答均拒绝。
- [ ] 来源资格由主进程读数据库，不接受 renderer 自造学习请求、答案、证据、状态或会话用途。不存在/非法轮次 UUID 明确报错，不回退使用当前页面内容或其他路线。
- [ ] 默认标题为学习前缀和保存目标的前 60 字符；详情保留完整 goal/query 及固定执行提醒，预计分钟来自保存的路线预算。检查多行/最长目标/检索词和中文、表情字符，不把模型回答截断塞入任务说明。
- [ ] 默认内容明确待执行，包含阅读/求证、练习、作品与复盘的行动提醒；不声称四步已完成、不推断掌握。完整原路线仍供用户核对，产品不能把固定提醒描述为已自动提取模型的所有步骤。
- [ ] 日期由用户明确安排，合法 YYYY-MM-DD，关联项目可为空或是使用中的项目。项目列表加载失败应显示错误，不把失败当作无项目列表；不存在/归档项目通过直接 IPC 请求也不能新增关联。
- [ ] `prepareTaskProposal(turnId, { day, projectId, edit? })` 只允许声明的字段；edit 只允许 title/details/minutes。拒绝 status、completedAt、来源、revision、SQL、路径、提示、工具和额外字段，不通过对象展开写入权限字段。
- [ ] 复用任务限额：标题单行非空且最多 120、details 最多 4000、预计分钟整数 5～480；边界值与超限、空标题、NUL、换行标题、错误类型、浮点/NaN/Infinity 分别验证。
- [ ] 日期规范与实际日历有效性沿用手动任务规则，覆盖闰年、0001/0099/9999 年及错误日期；不通过 UTC 解析改变安排日，不因当前日变化而静默改期。
- [ ] 起草、编辑和最终预览都不写数据库；不额外发模型请求、重新检索、解析模型 Markdown 工具指令或执行资料中的命令。未确认前任务数量/版本、学习时间、签到和记忆均不变。
- [ ] 最终预览完整展示主进程返回的标题、详情、日期、预计分钟、关联项目快照/版本及来源路线标识/版本；清楚表示将新增一项待完成任务，不是替换或完成已有任务。

## 4. P0：预览缓存、确认、拒绝与原子性

- [ ] 主进程缓存生成的 UUID、校验后的完整草稿、来源轮次版本及完整项目快照。无项目时快照为空；项目名称/目标/版本不能由 renderer 伪造。
- [ ] 缓存最多 10 份、有效 10 分钟；测试临界有效期、过期清理及超过容量的淘汰。过期、被淘汰、拒绝、已确认 UUID 再确认均不新增记录。
- [ ] 同一路线重新准备后旧 UUID 失效；修改标题/详情/分钟、日期或项目后旧最终预览不能确认，必须重新准备。新预览内容与用户最后编辑一致，旧异步结果不能覆盖新预览。
- [ ] `confirmTaskProposal(UUID)` 只收缓存 UUID，不接受 renderer 的最终正文、项目快照、状态、日期或来源。伪造 UUID、额外对象及错误类型明确拒绝。
- [ ] 确认时重新读取来源，核对用途、状态、请求、证据、答案和 revision；准备后来源修改/删除/失去资格均拒绝，无部分任务写入。
- [ ] 准备后项目标题/目标/revision 被编辑、项目归档或关联项目缺失时拒绝旧预览；即使归档后恢复也应因版本变化重新预览。无项目草案不因其他无关项目变化失败。
- [ ] 创建在 `BEGIN IMMEDIATE` 事务内重新核对关联项目快照/归档状态、全库任务数量、参数化 INSERT、返回行解码及提交；同步事务中不插入模型请求或其他 await。
- [ ] 任务上限 5000 包括所有日期与已完成任务。预览时未到上限、确认前达到上限仍拒绝；删除腾出容量后可重新确认有效预览，不删除旧任务或把当前日数量当全库容量。
- [ ] 正常确认只新增一项任务：主进程 UUID、todo、completedAt=NULL、revision=1、真实 createdAt/updatedAt、保存的草稿与学习路线来源。实际返回结果与数据库逐项一致。
- [ ] 重复点击和同步并发同一 UUID 最多一次成功写入；成功才消费缓存，后续确认不重复 INSERT。相同内容重新起草是新的显式提议，不宣称存在跨提议自动去重。
- [ ] 注入项目校验/数量查询/INSERT/返回行解码/提交失败，事务回滚、无残留半记录、不显示已保存，缓存和用户草稿保留以便恢复；原始错误不能被回滚错误掩盖成成功。
- [ ] 拒绝/取消仅撤销缓存，合法 UUID 的重复 discard 可按契约安全处理；没有创建任务、修改进度或把建议自动记录为学习轨迹。
- [ ] 异步 prepare 迟到、离开页面、切换路线和未确认预览卸载时清理缓存并拒绝旧结果。缓存清理失败有真实提示，不把清理失败描述为任务已新增。

## 5. P0：来源、重启与确认应答丢失

- [ ] 手动新建任务来源 manual/NULL 来源字段；通过提议新增来源为学习路线及真实轮次 UUID/revision。手动 API 额外提供来源字段被拒绝。
- [ ] 编辑、改期、改项目、完成和重新打开已确认任务保留原来源轮次/版本；另存新任务明确创建 manual，不复制主进程来源权限字段或悄悄替代原记录。
- [ ] 当前表单/删除预览/实际写入结果清楚显示来源；来源是当时版本，不把当前路线版本变化显示为原任务自动跟随更新。
- [ ] 查看来源打开对应保存路线/轮次，不请求模型或自动起草新路线；来源已丢失/无法读取时明确报错，不替换为别的路线。打开路线不覆写该页原有起草输入；切换到不同来源时原未确认提议按既有约定撤销。
- [ ] 正常关闭、重启后确认任务及来源完整恢复。缓存只在内存，不保存 proposal receipt 或可恢复预览；重启后的旧 UUID 确认失败，不宣称跨重启可以重发旧确认。
- [ ] 确认真正提交成功但 IPC 应答丢失时，记录仍存在；UI 提示去学习计划核对实际保存结果。不得声称已取消、保证没写入，或用新的提议自动重试造成第二条任务。
- [ ] 确认已发送后切页/隐藏/卸载，真实成功仍回调刷新计划；撤销预览不撤回已提交的确认。取消发生于确认之前则无写入，两种时序分别验证。
- [ ] 已确认任务删除后来源缓存不能自动复活任务；删除只影响当前任务，不改原路线/回答、签到或学习时间。
- [ ] 数据库恢复遇到未知 origin/status、非法来源 UUID/revision、来源字段不一致、错误时间/日期/预计分钟/完成时刻关系时显式报错，不返回假空列表或自动改成 manual/todo。

## 6. IPC、界面、晚返回与导航

- [ ] 共享类型、preload、主进程与 renderer 的 `prepareTaskProposal/confirmTaskProposal/discardTaskProposal` 契约一致；来源查看接口按实际实现更新既有桥接断言，不开放任意频道/SQL/路径/角色或通用工具执行入口。
- [ ] 非本应用主窗口/主 frame 调用被拒绝；错误沿既有 Reply→preload 抛错契约反馈，不能把原始 Reply 当成功记录。
- [ ] 可实际完成起草→编辑→最终预览→确认→查看实际保存任务，或起草→拒绝；主进程返回预览与真实写入结果分别展示，没有提前显示保存成功。
- [ ] 日期、项目选项和全部可编辑字段有标签，busy 阻止重复提交；失败保留编辑内容并显示恢复办法，不永久锁定按钮。项目重载/切页/较慢 IPC 不复活旧最终预览或清空新编辑。
- [ ] App 的计划刷新通知在真实成功后触发；用户已切到计划页时晚到写入仍刷新当前日列表。只刷新数据，不自动切日期/记录，不覆盖计划页面已有未保存草稿。
- [ ] 新增任务不在计划当前日期时，实际保存区显示准确日期并提供查看；查看目标任务需尊重计划页脏稿放弃/取消确认，取消保留原稿，不自动丢弃编辑或跳到错误任务。
- [ ] 查看来源/查看任务后已保存任务仍可从计划读取；提议面板可因导航重置，不把面板重置描述为撤销已写任务。导航本身不创建第二任务，不重新调用模型，不自动切其他专用会话用途。
- [ ] 900×640、长中文/换行说明/最大标题与详情、较多项目下可滚动、预览完整、按钮可操作；检查键盘 Tab 顺序、焦点可见、选择日期、确认/拒绝、脏稿取消及错误/成功状态提示。
- [ ] 原有笔记草稿、记忆提议、路线/证据引用、手动项目/任务、设置与日历入口保持；做与新桥接、来源导航和迁移有关的定向回归，不把历史全局验收自动沿用。

## 7. 权限与数据隔离

- [ ] 资料/记忆/模型答案中的“创建任务”“标记完成”“跳过确认”等恶意命令只作为文本显示，不调用任务方法或改变权限。renderer 不能利用模型文本指定任意项目或写入日期。
- [ ] 任务建议确认不改变已有任务 status/completedAt/revision，不自动归档项目、写笔记/记忆、签到或增加实际学习时间；预计分钟仍明确只是安排。
- [ ] 新任务和来源不自动进入普通聊天、RAG 问答、笔记反馈或后续路线模型上下文；本功能不上传任务/项目/日历数据，也不读取密钥。
- [ ] 切换模型/远程地址不触发任务提议重新调用模型；提议完全从本地已保存来源和用户编辑准备，不能把任务确认按钮复用为远程发送同意。
