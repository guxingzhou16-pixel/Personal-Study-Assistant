2026-10-07固定候选及独立文件校验的回执见 [发布验收总表](release-readiness.md)；[候选版说明](../releases/0.1.0-candidate.md)为草稿，不是公开下载公告。由总表核对确切源码/包摘要后再执行本清单，旧UUID产物或同名0.1.0安装器不代表同一候选。

2026-10-09更新候选固定为`ce9caae`，含恢复期限、全量专注历史与独立修复整合；当前产物及独立摘要以总表为准。原独立/修复记录只适用于旧源码，当前版先执行[收尾复验清单](first-release-closeout-2026-10-09.md)，再隔离运行正式包；下面安装/发布条件仍未执行。

目标为 Windows x64；Electron 44.5.1、electron-builder 26.15.3、ASAR 检查工具 4.3.1，版本由锁文件固定。当前主库 v12 / 活动库 v1 / 派生索引 v2 / 完整备份格式 1；v12 练习迁移和旧 11/1 备份兼容政策见 [练习清单](practice-acceptance.md)。打包本身不新增迁移。当前包未签名、无自动更新；配置不发布，构建脚本不启动软件或安装器。

**实际安装/启动必须使用独立 Windows 测试用户或可恢复的虚拟机。** 正式包刻意忽略 `STUDY_COMPANION_DATA_DIR` 和开发 URL 环境变量，使用该测试用户的 `%APPDATA%\StudyCompanion`；仅设置临时目录环境变量不能隔离正式包。不得在个人用户下启动产物、安装/升级/卸载来代替验收，不使用私人资料、真实密钥或收费模型。保存日志时避免用户内容和凭据。

## 1. 构建、来源与失败

2026-10-09分发收尾补充：[第三方说明](../third-party-licenses.md)记录按实际包生成的全文/元数据/来源及未完成条件；[隔离流程](isolated-installation-acceptance.md)提供离线Sandbox材料和真实保存/替换/卸载/重装步骤。用户已明确要求本对话完成这一范围的验收；本机未启用Sandbox或提供VM前，实际运行仍保持未执行。材料准备、许可摘要和同版替换不代替安装业务值、完整分发核对或跨版本升级。

- [ ] 记录提交、工作区状态、Windows/Node/Electron 版本、CPU 架构、具体命令和输出目录。在 Windows x64、Node >=24.16 的干净克隆中用 `npm ci` 重建，不复用开发目录的旧 node_modules 或旧 dist。
- [ ] `npm run desktop:pack` 和 `npm run desktop:dist` 分别先做生产构建，再生成完整目录包或 NSIS。无需 C++ 工具、源码重编译或聊天模型；首次依赖/NSIS 工具下载需要网络，缺失/失败明确报错，不自动换下载来源。
- [ ] 每次输出 `release/dir-UUID/` 或 `release/nsis-UUID/`，不会覆盖旧成功回执。失败目录可能残留，仅有 build-info 或 package-audit 不能当完成安装包；没有成功的 build-manifest/SHA256SUMS 时保持失败状态。
- [ ] build-info 的版本、Electron、构建工具、Node、Git HEAD、已追踪改动标志、锁文件 SHA-256 与开始打包时真实状态一致；包内资源同一份来源。记录发生在 desktop:build 完成之后，不保证此前编译期间源码没有改变；干净发布构建须固定提交且禁止并行修改。dirty 明确表示含未提交修改，不能宣称对应纯提交/已验收标签。
- [ ] 构建期间 HEAD 变化拒绝成功清单；非法模式或非 Windows x64 构建机拒绝，不接受额外发布参数、路径或平台。缺资源、错入口或打包失败不显示成功。
- [ ] build-manifest 的 packageAudit 只为 `static-package-contents`，功能状态始终 pending；安装器字节数/散列与 SHA256SUMS 一致。目录模式散列覆盖 win-unpacked 的全部普通文件，含解包 worker/依赖/DLL；链接或特殊文件拒绝成功，不漏算实际运行文件。哈希不证明真实性。
- [ ] 构建和校验均不请求模型、读取应用数据库、自动启动应用/安装器、运行功能测试、提交或推送 Git。发布参数始终 never，配置 publish 为 null，即使 CI 存在 GitHub 凭据也不创建 Release。
- [ ] NSIS只通过npm包装构建：核对同实例app-builder-lib26.15.3、唯一setup路径/空参数/首个调用的WineVmManager适配，用已有UninstallerReader纯文件提取一次卸载器；未知请求/失败不回退执行，finally还原。builder升级或绕过包装不能沿用本次边界结论，不直接运行npx electron-builder。
- [ ] 网络/代理失败和工具缓存EXDEV保留失败状态；临时代理与ELECTRON_BUILDER_CACHE只作用当前构建进程，不写入项目，不关闭TLS/工具摘要校验，不自动清除系统缓存或修改学习数据。

## 2. 包内容与运行资源

- [ ] ASAR 顶层只含 dist、dist-electron、生产 node_modules 和 package.json；包内 package.main 为 dist-electron/main.cjs，版本与来源记录一致。无 README/AGENTS、源测试、第三方下载目录、人格文档、学习库/资料、备份、密钥、模型权重或索引。
- [ ] main/preload/renderer 在 ASAR，三个 ESM worker 在 app.asar.unpacked/dist-electron；workerDirectory 正式模式读真实文件、开发模式保留原目录。检查实际模块解析，不只检查文件存在。
- [ ] PDF.js 解析模块及本地 CMap、字体、WASM、renderer JS/CSS/PDF worker 完整；没有依赖工作区绝对路径、localhost 开发服务、浏览器 CDN 或仓库 public 目录。
- [ ] Transformers 的 node ESM 导出、ONNX Runtime Node Windows x64 的 .node/.dll、Sharp 实际 ESM/CJS 导出和 x64 原生文件及其传递依赖可读；没有混入 ONNX Linux/macOS/ARM64 绑定。不能用文件存在代替成功推理或故障降级验收。
- [ ] 移走/断开源码目录与 node_modules 后，在隔离用户/VM 启动目录包和安装版仍能读资源；不能因为开发机全局依赖或 cwd 恰好是仓库而掩盖错误。
- [ ] 在带中文与空格的安装位置及普通用户权限下启动；不写安装目录，不要求提升权限或从系统安装 C++ 工具。第三方许可证/运行时分发要求在发布前核对。

## 3. 安装、升级与卸载

- [ ] 先核对 SHA-256 和实际签名状态。当前为未签名候选，未知发布者/系统提示如实记录，不关闭系统保护；哈希不证明发布者身份或软件安全。
- [ ] 当前用户的一次点击 NSIS 安装、开始菜单“拾知”和 StudyCompanion.exe 可用，不安装为所有用户、不创建默认桌面快捷方式；安装完成不自动启动应用。手动启动不依赖 Node/Git 或开发服务器。
- [ ] appId 保持 `io.github.guxingzhou16pixel.studycompanion`，Windows appUserModelId 与之相同；appName/数据目录仍为 StudyCompanion。版本/产品信息可识别，临时默认图标不冒充已完成品牌资源。
- [ ] 在隔离用户写入合成资料、笔记、路线/记忆、项目/任务、专注/复盘、签到、主题和假密钥，关闭/重开仍恢复原值，应用写入实际测试用户的 APPDATA。
- [ ] 升级前保存草稿、结束活动并退出软件，保留完整备份后安装新包；安装目录变化不创建第二套学习数据，既有 appId 不能随意更改。实际迁移按 v5～v12 清单验收，不只比较页面数量。
- [ ] 单实例行为、安装取消、重复安装、磁盘/权限失败、正在运行时升级提示均在 VM 验证。强制关闭可能丢未保存草稿，不宣称升级自动保存或无中断。
- [ ] 卸载仅移除应用/快捷方式；配置 deleteAppDataOnUninstall 为 false 的实际行为保留两库、资料、密钥、本机模型、恢复位置/旧目录与备份。不运行自定义清理，不把保留数据误称卸载失败。
- [ ] 卸载后重新安装能读取原保存内容，测试过程中保持副本；文件损坏/缺失不能悄悄重置成空库。不同 Windows 用户之间不混用数据，机器绑定密钥不承诺跨用户/跨机解密。

## 4. 正式包的学习流程与隔离

- [ ] 检查首页日历/计时、资料导入与后台进度/取消、PDF/Markdown 原页/排版/护眼/位置、笔记/导出、主题/设置，在没有源码的安装版中可操作。
- [ ] 原始包不含聊天模型或 BGE 权重；未配置模型时错误明确，关键词路径可用。主动下载 BGE、CPU 语义检索/缓存/取消/损坏降级单独验收，不自动调用付费 API。
- [ ] 使用获准的本地/模拟服务验证流式聊天、停止/恢复、出处跳转、笔记反馈、受控路线/记忆选择；远程确认与密钥地址绑定保持原边界，不因打包放宽 CSP/沙箱/IPC。
- [ ] 手动项目/任务、Agent 单任务确认、任务关联专注/中断/复盘与独立签到按对应清单验收；不自动把中断记完成或将预计分钟当实际时长。
- [ ] 备份 worker 在安装目录可运行，完整两库/资料导出、取消、恢复预览/确认重启/旧数据保护可用；位置损坏报错、正式包不能靠临时目录环境变量偷偷换学习目录。
- [ ] 设置开发 URL、临时数据目录等环境变量时正式包仍按生产规则处理；任意窗口/子 frame/导航不获得 IPC 或用户文件权限。
- [ ] 900×640、三种主题、键盘/焦点、缩放、长中文路径、睡眠/重载/退出、用户取消笔记关闭确认按集成要求验收，失败保留复现证据。
