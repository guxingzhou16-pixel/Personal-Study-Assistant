## 1. 环境与真实样本

- [ ] 记录实际源码提交、Windows/Node/Electron版本、设备时区和隔离数据目录。开发测试用临时`STUDY_COMPANION_DATA_DIR`，正式包用独立Windows用户/VM；不打开个人APPDATA或私人资料。
- [ ] 用可生成任务与人工专注记录准备0、1、20、21和多页数据；包含已计满/提前结束/不同中断原因、正在运行/暂停、有无复盘、中文/长标题/1000字符复盘、相同startedAt和来源任务改名/改期/删除。
- [ ] 保存两库逐表基准、UUID/revision/elapsed/时间/来源快照及资料哨兵。历史查询与选择不请求模型、不读取密钥、不改任何记录、计时状态、任务完成或签到。

## 2. 只读查询与分页

- [ ] 参数只允许显式`day: null或合法0001～9999的YYYY-MM-DD`、`page:1～500整数`。缺字段、未知字段、错误日期/闰日、数组/字符串/布尔页码、0/501/小数/NaN/Infinity、SQL/任意limit/排序/路径均拒绝。
- [ ] 仅返回completed/stopped/interrupted，排除running/paused；按真实开始毫秒倒序、同刻UUID升序。每页固定20，total属于本次实际筛选范围，空结果page=1，合法但超出当前最后页的页码返回实际最后页。
- [ ] 20/21条、相同开始时刻、第一页/最后页/重新筛选的数据不重不漏；同一静止数据集合中的拼接结果与独立基准一致，不因SQLite行顺序或复盘更新时间重新排序。
- [ ] 超出10000终态记录或损坏元数据/所选行明确报错，不静默丢记录、截成成功或把未解码行发往界面。只返回本页完整记录，元数据扫描有10001条上限，不把整个复盘库交给renderer。
- [ ] 查询直接使用Storage，只读，不调用FocusTracker.overview/checkpoint/故障恢复写入；专注继续时查询也不额外推进elapsed/revision。后台存储故障提示与原main调用方/主frame校验保持，备份维护期间拒绝历史IPC。
- [ ] 开始/结束新专注或保存复盘后刷新读取当前数据。跨请求页位置可能变化，界面不承诺冻结快照；静止集合验证与并发插入场景分开记录。

## 3. 开始日期与时区

- [ ] 日期按startedAt在**当前设备时区**的日历日筛选，与任务安排日期taskDay分开；跨午夜或任务改期不把历史移动到任务日期。界面显示实际筛选条件，不把尚未提交的日期输入当成已生效。
- [ ] 本机午夜前/恰好午夜/午夜后、UTC与本机日期不同的样本准确。切换测试设备时区后重新读取按新时区计算，不声称保存了专注开始时原时区快照。
- [ ] DST切换日、跳过的日历日、0001/0099/0100/9999年、跨UTC扩展年份但本机仍为9999年的合法时刻正确；不使用固定24小时或规范ISO字符串排序误判日期/顺序。时区测试在独立进程执行，不更改用户系统时区。

## 4. 旧复盘与草稿保护

- [ ] 初始面板折叠且不查库，展开才读取；全部/日期筛选/分页/刷新均只读。选择滑出最近20条的历史记录后，父页按ID重新读取实际保存版本，展示完整复盘/状态/原因/elapsed/时间/来源快照，并将焦点移到复盘标题。
- [ ] 当前复盘有未保存修改时，载入另一记录仍经过原“继续编辑/放弃并查看”确认；取消或Escape保留旧稿/ID/revision。只筛选、翻页、折叠历史不覆盖编辑区或自动保存。
- [ ] 手动选择的旧复盘在另一活动专注结束或最近列表刷新时保持所选记录；未手动选择时原新结束记录展示仍可用。脏稿始终保留，不能把新记录内容绑定到旧ID或反过来。
- [ ] 保存旧复盘返回实际FocusReviewResult，只更新原ID的review/revision/updatedAt；历史面板刷新显示实际结果。冲突/应答丢失仍需重新读取核对，不自动重发、不覆盖草稿。原计时、来源和其他记录不变。
- [ ] 查看关联任务走原计划页真实读取与脏稿确认；已改名/改期/删除的任务不伪造可用旧任务。查看、选择或复盘不会自动开始专注、完成任务、签到、写掌握评价。

## 5. 竞争、失败与桌面体验

- [ ] 日期A/日期B、页码、刷新请求乱序，以及折叠/切页/隐藏/卸载后的迟到结果不覆盖当前列表；新查询期间旧列表不可误选。开始/保存操作忙碌期间查询/选择不干扰，恢复可操作后能重新读取。
- [ ] 旧复盘详情读取期间切离页面，迟到结果不弹确认或覆盖草稿；失败解除busy并显示具体错误，不误报已载入/已保存。重试详情仍只读。
- [ ] 新结束记录或成功保存复盘只触发必要刷新，不随每秒overview.version反复查历史；正在输入的筛选日期、当前页和正在编辑的复盘按约定保留。
- [ ] 系统时钟回拨或合法备份含未来记录，当前轮自动计满/中断但recent首项ID不变，仍由活动ID转为终态触发历史刷新；即使新结束记录未进入最近20条也生效，不靠最近首项判断，不每秒重复刷新。
- [ ] 浏览器预览明确要求桌面版，不伪造记录；无记录/无匹配/读取失败/加载中均有准确状态和重试入口，不用旧页数据表示新查询成功。
- [ ] 900×640、缩放、三种主题、长中文标题/复盘、列表滚动；日期/筛选/刷新/分页/折叠/选择/确认支持键盘、可见焦点、标签、aria-expanded/pressed及状态提示。历史详情载入后焦点可见，取消草稿确认回到合理位置。
- [ ] 原最近20条、番茄控制/计时中断/复盘/签到、计划跳转和备份维护锁定向回归；资源与10000条规模耗时另测，不能以类型检查或本清单声称性能/桌面通过。
