# 有资料依据的知识卡片与短测验：独立验收清单

## 范围与当前状态

2026-10-06：学习助手新增“知识卡片”和“短测验”，主题/范围 → 本地检索原文预览 → 配置绑定/远程确认 → 一次生成 → 3 项结构与出处校验 → 翻面/手动作答/对照答案。**2026-10-08 已执行程序校验和源码 UI；真实测验语义有失败，范围和剩余条件见末尾执行记录。** 主线只类型/生产构建/格式/diff/静态审查，没有运行测试、桌面、安装器、任何数据库或模型；生成效果不能由构建通过推断。

练习仍是普通 `purpose=chat` 会话中的 `mode=sources` 轮次，通过可空 `practice_request` 明确用途。它不进入普通聊天上下文，不带笔记/记忆/计划/时长或旧练习；支持既有历史切换/重启/删除/导出。不新增账户、间隔复习、自动评分、作答持久化或掌握记录。

当前主库 **v12** / 活动 **v1** / 派生 **v2** / 完整备份格式 **1**。v12 只新增轮次 JSON 列，不重建旧表/改写旧行；旧行 NULL。完整备份只支持 **12/1** 同版本校验，旧 **11/1 文件夹备份本版拒绝**；用对应旧版在隔离环境恢复，再升级该数据目录。直接打开旧主库可前向迁移，不等于接受旧文件夹备份，禁止只改清单或 `user_version` 绕过精确 schema 校验。

开发版使用临时目录、合成 PDF/Markdown、两协议模拟服务/假密钥。正式包用独立 Windows 用户或可恢复 VM，不在个人 APPDATA 下运行；旧候选包不含本轮代码，验收前按记录提交重新构建。详见 [安装清单](packaging-acceptance.md)。

## 二、请求、预览与隐私边界

- [ ] 两个新增具体桥接 `preparePractice({ kind, topic, sourceId })` / `sendPractice({ conversationId, retrievalId, expectedProfile, consentEndpoint? })`；旧桥接列表断言由测试方同步，preload 解包契约正确。主窗口/main frame 权限与沙箱保持。
- [ ] kind 只 cards/quiz，topic 修剪后非空且最多 1000 字符，sourceId 为实际格式 SHA-256 或 NULL；未知字段、错误类型/ID、renderer 提供 prompt/答案/证据/工具/路径均拒绝。
- [ ] send 只收 UUID 和确切配置/确认地址，不接受请求正文或自造证据。conversationId 必须普通 chat 会话；猜测 feedback/learning-agent 会话 ID 或不存在 ID 拒绝，不产生专用轮次。
- [ ] prepare 最多一次现有检索，中文关键词/混合/降级文案、进度/取消与原文预览沿用；不因用户取消重试、请求模型或自动生成空说明。
- [ ] 缓存 10 份/10 分钟：界面改主题/类型/范围或重新检索后撤销旧预览/同意；主进程拒绝过期、已消费或丢失底层证据的 ID。未消费缓存只代表其原始请求，不接受新正文或改写证据；渲染端匹配主题/范围/类型及配置。
- [ ] 检索前后与发送时核对 provider/baseUrl/model 签名；服务/模型变化后必须重准备，不能以旧确认发到新服务。远程勾选绑定接口/地址/模型/类型/预览 ID，真实发送主题/类型/3项要求/当前证据，费用提示明确。
- [ ] 保存配置 A→B→A 后旧预览/远程勾选仍已撤销；变配置、切换/新建会话或取消时推进请求版本，迟到成功不能填回预览。取消应答与检索结束交错不永久 busy，也不让迟到取消作用于新的检索。
- [ ] 普通聊天/资料问答的预览 ID 不能直接充当练习缓存；互换调用时不得把新的正文或模型提示拼进旧证据。
- [ ] 本机两协议不因练习读云密钥；兼容远程只读取对应地址密钥；空证据无模型请求、无密钥读取，只保存真实本地不足说明，正 revision=1 可备份。
- [ ] 普通聊天最近 6 轮历史不包含练习（包括completed），练习不发送任何旧会话、笔记/记忆/任务/签到/时长或本地作答。用户在同会话切回普通聊天不改变该规则。
- [ ] 主题和证据中的 prompt 注入不授权工具、写任务/记忆/进度或执行脚本；服务无任意工具 dispatch，也不因错误自动重试或换模型。

## 三、结构与生成状态

- [ ] cards/quiz 均只接受一个完整 `{ items: [...] }` JSON，恰好 3 项，每项只有 question/answer/citations；可接受一个完整外层 JSON 代码围栏，不从额外正文中猜测/抽取 JSON，不自动修复。
- [ ] 每个非空问题≤500字符、非空答案≤2000，原始输出≤10000字符；超长、少项/多项、额外字段、空值/数组替代对象、错误类型都报练习未完成，保留原始文本，UI 无可交互题目。
- [ ] 每项至少一个实际检索编号，数字整数/实际存在/不可重复，拒绝未知编号、字符串、NaN/负数/小数/空数组；重复问题（修剪与大小写归一）拒绝。
- [ ] 编号合法仅证明出处存在，不能证明答案语义受支持；独立真实模型验收另外核对答案每一要点和问题歧义，保留不支持/编造/重复语义等失败案例，不宣称准确率100%。
- [ ] NDJSON 与 SSE 正常完整输出通过共用 streaming/500ms保存/单活动请求；不另开第二套网络管线，早到事件不被 invoke 初始快照覆盖。
- [ ] 格式无效、资料不足说明、空回答、断流、超时、长度截断、服务故障都明确未完成。正常完成标记但输出被截断也不得completed；不得只因收到完结标记认定练习成功。
- [ ] 点停止后 late chunks/晚完结不改变状态或追加文本/题目；退出恢复不自动请求模型。停止与结构验证交错仍不复活completed。
- [ ] 空证据本地说明标为完成的是“说明”，没有 3 项练习，不误显示答题或模型已生成；与主库/备份正 revision 规则一致。
- [ ] 保存失败不冒称成功，状态/notice 清楚，持久版本与显示可能不同的风险按既有管线处理。

## 四、翻面、作答与引用

- [ ] 学习助手两新模式/资料范围/主题限额/检索/完整预览/确认/“生成3项练习”可发现且可操作；从阅读“问这份资料”进入后可选练习，限定来源仍有效。

- [ ] 作答从未通过桥接/网络/日志/备份/Markdown导出发送或保存。会话切换/重载/关闭可能丢失已提示；引用往返组件仍在时保留内容，不承诺跨重启草稿恢复。
