## 本版能力

- PDF／Markdown导入、排版阅读、阅读位置保存和原文引用；扫描PDF可看原页，OCR与更多格式后续开发。
- Ollama及兼容OpenAI接口的流式聊天，关键词／本机BGE混合检索、证据预览和出处返回。
- 四部分笔记、资料反馈、受控学习路线、卡片／简答测验；任务与长期记忆分别预览确认才写入，不自动评价掌握或完成。
- 学习项目／每日任务、任务番茄钟、专注历史／旧复盘、真实签到与计时、三种主题及历史导出。
- 已保存资料与两库完整备份、预览确认后恢复重启；备份未加密，不包含API密钥或模型。

## 平台与模型准备

目标为Windows 10／11 x64，实际正式包补验环境为Windows 10.0.26100的真实Sandbox。安装版不要求Node、Git或C++编译工具；本机聊天服务与模型需用户自行准备，兼容远程接口费用由用户承担。

聊天模型与BGE权重不随包分发。无模型时可阅读、手写笔记、做计划和专注；BGE是可选检索模型，不替代聊天模型。正式ONNX CPU检索需要可用的Microsoft Visual C++ v14 x64运行库；用户按设置中的官方入口安装后重启应用，应用和安装器不自动安装或捆绑它。
