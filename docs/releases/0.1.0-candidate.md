## 本候选包含的实现

- 首页今日任务和六步学习入口，真实签到/月历/手动计时；计划和专注仍需用户明确操作。
- PDF/Markdown导入与排版阅读、保存阅读位置、复制原文引用。
- Ollama和兼容OpenAI接口的流式聊天；关键词/本机BGE混合检索、证据预览与出处返回。
- 四部分学习笔记、依据资料的AI反馈、一次检索后起草学习路线、手选记忆和确认新增单项任务。
- 有资料依据的固定3项卡片/简答测验；手动作答对照参考答案，不自动评分或认定掌握。
- 项目/每日任务、任务关联单轮番茄钟和复盘；三种视觉主题、会话/路线历史管理与Markdown导出。
- 已保存的两库及资料完整备份/恢复预览与确认；不包含API密钥、本机模型或可重建索引。

上述为代码已接入的范围，实际通过与失败必须按详细清单记录。受控路线不是可任意执行命令的Agent；确认提议才新增记录，不从模型评价自动推断掌握或完成。

## 平台与模型准备

目标平台为Windows 10/11 x64；逐系统版本和安装后的运行尚待验证。构建机需要锁定依赖对应的Node/npm/Git，使用者运行安装版不应需要开发工具，但这点也须在隔离环境验收。

包不附带聊天模型或BGE权重。未配置模型时先使用资料阅读、手写笔记、计划和专注；AI功能由用户在设置中配置Ollama或兼容接口。BGE为用户主动下载的可选本机检索模型，约23.3MiB，不能代替聊天模型。远程调用由用户确认发送内容，费用由用户自行承担，不要求在仓库或聊天中提供密钥。

## 安装交接

本候选无公开下载入口。测试方先从 [验收总表](../testing/release-readiness.md) 核对固定提交、完整目录/安装器和SHA-256，再按 [Windows安装清单](../testing/packaging-acceptance.md) 在独立Windows用户或可恢复VM安装、手动启动。目录包必须完整保留，不能只复制EXE。

当前为未签名候选、默认Electron图标、无自动更新；不关闭系统保护。配置为当前用户安装、开始菜单“拾知”、不默认创建桌面快捷方式、安装后不自动启动，实际行为仍待验证。后续更新由用户获取经验证的新包；目前没有经过验收的更新通道。

## 保存、升级与恢复

- 数据根为该Windows用户的 `%APPDATA%\StudyCompanion`。正式包忽略开发模式的临时数据目录变量；测试不能靠该变量隔离个人数据。
- 升级前保存输入、结束活动、退出并保留完整数据副本。关闭/重载/强退可能丢失未保存稿，模型回答或计时中断不自动重发/续计。
- 本版主库v12、活动v1、派生索引v2；完整备份format1只接受12/1。旧11/1备份不能由本版直接恢复，须用对应旧版在隔离环境恢复后前向升级，不能更改版本字段冒充兼容。
- 恢复是整份替换，不合并；备份未加密，含私人学习内容，不导出密钥/密文。隔离源码的两库/资料往返、启动切换和手动回退已测试，阅读位置非法 tone 可阻断备份（F1）；正式包及物理磁盘/断电故障未验收。细节见 [README](../../README.md) 与独立报告。
- 卸载配置保留数据，但实际升级/卸载/重装行为未验收。不要用个人用户试错；旧应用不保证能读新数据库，软件降级不能代替数据回退。

## 已知限制与发布前待办

- 首版只接PDF/Markdown；扫描PDF可看原页，OCR、更多格式、账号/云同步、展示网站未实现。
- 知识卡片/短测验和RAG引用有结构/来源校验，不能由此保证答案语义正确；本机 qwen 小样本存在引用不支持回答、笔记快照误读、路线预算不符和测验扩展证据的失败；独立检索两题完整召回失败，真实云模型未验收。
- 最小900×640窗口的设置导航不可见（F2）；现代主题“分钟”等普通文字对比度不足（F3）。实现方需新提交和复验，再生成新 UUID 候选，不能替换此包的来源或字节。
- 无自动评分、作答持久化、间隔复习、批量任务拆分、番茄钟休息连轮或系统通知。
- 完整备份、恢复旧目录、失败候选与模型可能占用磁盘；没有自动清理或自动备份。未保存稿不属于备份内容。
- 生产构建保留大资源块提示；源码中500份预置合成Markdown/9000 FTS块的查询和取消已有样本，不能作为真实PDF批量导入、大规模向量、峰值内存或安装后性能承诺。
- 项目许可证、依赖分发许可/通知、远端CI和公开发布授权仍待核对。验收、许可与授权完成后再形成正式发布说明、标签与下载入口。
