## 4. 库替换与修改范围

正式应用的实际相对目录为：

```text
resources/app.asar.unpacked/node_modules/@img/sharp-win32-x64/lib/
```

其中包含 `libvips-42.dll`、`libvips-cpp-8.18.7.dll` 与 `sharp-win32-x64-0.35.5.node`。关闭应用后才处理替换，先保存原文件；使用与链接版本接口兼容的修改库，保留必要依赖。MSVC C++ ABI/导出和调用约定仍需兼容，不能因文件名相同就承诺可用。无效文件、依赖缺失、恶意修改或任意 ABI 改动不属于既有验证范围。
