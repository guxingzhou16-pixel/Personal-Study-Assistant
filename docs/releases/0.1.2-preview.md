# 拾知 0.1.2 预览版（Windows x64，未签名）

这是 0.1.1 首次预览发布后的维护更新。版本号为 0.1.2，标签为 v0.1.2-preview.1；提供完整 NSIS 安装包。

## 本次更新

- 整理晴岛界面、动效与减少动画模式；顶部导航收为学习首页、资料库和学习助手。
- 首页展示真实的路线、笔记与今日任务摘要；计划、专注、复习和记忆集中到设置的学习工具。
- 设置新增版本信息、更新说明、手动检查及官方发布页入口；更新仍由用户下载和安装。
- 改善阅读侧栏、来源跳转、草稿保留、结构化学习路线和任务确认体验。
- 修复资料检索中英文普通词过滤、复习版本冲突恢复、批量任务顺序和日历滚动等问题。
- 整理组件、测试和文档目录，增加项目内的本地最新版启动入口，便于后续维护。

完整源码差异见 [首版以来的更新汇总](../testing/main-update-summary-2026-10-22.md)。该历史统计截至 f310e97，后续版本准备和交付文档提交不计入原统计。

## 安装与数据

支持 Windows 10/11 x64。安装包未签名，Windows 可能显示提示；不要关闭系统安全保护。无需另装 Node.js、Rust 或编译工具。

升级前在旧版保存内容，建议导出完整备份，然后关闭应用并运行新安装器。安装到当前 Windows 用户，卸载保留学习数据；恢复备份会整份替换，不能当作合并。软件检查更新不会自动下载或安装。

主库 v13、活动库 v1、派生索引 v2，备份 format 1 不变。模型和 API 由用户自行配置；BGE 模型不随安装包捆绑，未准备模型时仍可阅读和关键词检索。本地语义检索可能需要 Microsoft Visual C++ v14 x64 运行库。
