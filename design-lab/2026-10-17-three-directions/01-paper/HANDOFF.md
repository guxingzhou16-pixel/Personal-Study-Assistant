## 要带给用户的感觉

走进一个安静、有人情味的小书房。视觉焦点放在“接着读”和正文，日历、签到、计时处于辅助位置。适合希望学习软件像书而不是控制台的用户。

记忆点是宋体类中文标题、苔绿书封、暖纸底色和斜放的日期印记。不要再添加背景照片、浓重阴影、玻璃效果或大面积渐变。

## 视觉约定

| 项目                   | 值 / 约定                                                            |
| ---------------------- | -------------------------------------------------------------------- |
| 主底 / 纸面 / 侧栏     | `#f7f5ef` / `#fdfbf7` / `#eeece4`                                    |
| 文字 / 次文字 / 分隔线 | `#343a31` / `#72766b` / `#dfdfd4`                                    |
| 强调 / 强调文字        | `#53674b` / `#fffdf4`                                                |
| 字体                   | 标题：本机宋体类；正文：Segoe UI / 微软雅黑；英文标签保持克制        |
| 字阶                   | 首屏标题约 40px；卡片标题 22px；阅读正文 14px / 2.1；辅助标签 9–11px |
| 间距                   | 页面左右 40px；主副栏间 37px；段落按 8 / 12 / 16 / 24 / 28px         |
| 材料                   | 主阅读卡片接近直角；书封有轻微倾斜；其他区域优先分隔线，不叠多层卡片 |

具体 CSS：`shared/demo.css` 的默认 token、`01 / Paper room` 段和阅读/资料库共用段。对应 HTML：`shared/demo.js` 中 `home()` 的 `paper` 分支。`body[data-theme="paper"]` 是此方向的选择器。

## 页面与演示行为

- 今日学习：侧栏 204px；主阅读 + 224px 周历/手动计时栏；最近资料为开放列表。
- 资料库：三列卡片、名称/主题搜索、格式筛选、空结果。
- 阅读：目录、独立纸面、宽屏 292px 助手；引用编号回到高亮原文。
- 900×640 仍使用桌面结构，主区纵向滚动。小于 760px 收为图标侧栏、首页单列；小于 430px 资料库单列。
- 工作中的按钮只操作内存示例。导入、设置、第二/第三份资料和问答提交会解释范围。刷新重置签到、计时和问题。

## 正式产品怎么接

先迁移 token 与页面框架，再改 `RecentReadings.tsx`、`LibraryPage.tsx` 和 `StudyCalendar.tsx` 的视觉，最后考虑阅读与助手的同屏布局。数据来源继续用现有组件和 `desktop.ts`，逐项替换示例值，不复制静态 HTML 注入方式。

本稿周历不是对正式月历的删除方案。PDF 阅读仍由 `PdfPage.tsx` 展示原页，本稿 HTML 文章只供排版参考。资料引用仍须走 `resolveCitation`，不能把 DOM 滚动模拟当作真实资料定位。

本稿没有结构化笔记、任务或长期记忆写入；左侧“学习主题”只是示例资料筛选，不宣称已有学习项目管理。

## 参考、验证与后续取舍

主要参考 [Readwise Reader](https://readwise.io/read) 的阅读优先和资料组织；纸张配色、书封与日期印记为本轮原创。详见 [参考档案](../REFERENCES.md)。

实际验证范围见 [VALIDATION.md](../VALIDATION.md)。正式实现前仍需用真实中文 PDF、Windows 缩放 125%/150% 和长标题检查可读性。辅助标签在最终产品中可以加大；不要为了保持截图紧凑而牺牲阅读。

如果选它，下一步先确定：宋体标题是否保留、主页周历与正式月历如何并存、计时是否继续放在右栏。无需为此预先搭建多主题框架。
