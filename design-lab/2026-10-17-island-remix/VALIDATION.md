## 静态检查与评审

- 三份 `design.json` 通过本轮 `handoff.schema.json` 的完整 JSON Schema 校验。
- 新写两份 JavaScript 通过 `node --check`；自写文件通过 Prettier 检查，上游 CSS / 许可证未格式化。
- 一般代码评审与 JavaScript 专项评审未发现剩余实质问题。
- 目录注册、截图、交接和产品映射路径核对通过；完整源码路径按 `.gitignore` 忽略。
- 自写文件的 Git diff 空白检查通过；Halfmoon 的上游许可证注释含原有行末空格，按锁定摘要保留，不重新格式化。原版设计目录无改动。

## 未验证与限制

- 所有资料、日期、问答、签到和时长均为示例。问答是固定内容，提交问题只说明演示范围；计时不是番茄钟。
- 未修改正式 React / Electron 应用，未验证 IPC、持久化、真实 PDF、真实模型、安装包或远端 CI。
- 本轮复用第一轮共享 CSS/JS；单独移动本轮目录时需一并保留第一轮共享目录。直接打开整个项目中的入口无需安装依赖。
- 系统字体会随机器变化；未进行 Windows 125%/150% 缩放、屏幕阅读器认证或长期阅读舒适度测试。辅助标签在正式实现时仍可加大。
- 上游 CSS 仅用于本地组件参考，三套软件设计没有把这三个框架接入正式应用。
- 一次性浏览器检查与原始结果保存在忽略的 `artifacts/ui-design/`，未加入正式测试套件。视觉检查通过不表示用户已经选定最终风格。
