## 设计目标与固定排版

像坐在一间有日光的编辑工作室。纸面、资料、摘记有秩序，字体稍带出版物的分量。暖色来自材质感，不靠大片饱和橙填满页面。

**布局锁定第一轮「03 晴岛」**：87px 顶部导航、约 1130px 居中主区、欢迎横幅；下方左侧继续阅读／资料，右侧 300px 签到／手动计时。资料库的卡片网格、阅读页的目录／正文／305px 助手也沿用晴岛。原版只是对照，不计入本轮三个新方案。

[晴岛原版](../../2026-10-17-three-directions/03-island/index.html) 不修改。本方向只改变配色、字体、圆角、边界和插画／封面外观，方便用同一结构比较风格。

## 视觉约定

| 项目                   | 值 / 约定                                       |
| ---------------------- | ----------------------------------------------- |
| 背景 / 表面            | `#faf6ef` / `#fffaf3`                           |
| 主文字 / 次要文字      | `#493b31` / `#88796b`                           |
| 强调 / 强调文字        | `#ad5136` / `#fffaf3`                           |
| 边线 / 欢迎区 / 计时区 | `#dfd2c3` / `#eee2d2` / `#e9ddcd`               |
| 字体                   | 首页宋体类标题 36px；界面和阅读正文为系统无衬线 |
| 阅读正文               | 沿用晴岛 14px / 2.1，系统字体                   |
| 圆角与边界             | 阅读区 6px、主卡片 14px、欢迎区 18px            |
| 间距                   | 沿用晴岛 8 / 12 / 18 / 24 / 28 / 31 / 38px      |

米白为主背景，暖纸色区分欢迎和计时区域；陶土橙只承担主要操作与少量强调。首页使用本轮原创翻书与陶土日轮 SVG。宋体集中用于标题，避免把整套工具都变成书籍正文。系统字体回退不增加下载成本。

实现入口的 `body` 保留 `data-theme="garden"`，追加 `data-variant="terra"`。第一轮 `shared/demo.css`／`demo.js` 提供页面骨架，本轮 `shared/variants.css`／`variants.js` 提供覆盖；不要为了改这套设计去覆盖原轮文件。

## 演示与正式接入

首页、资料库和阅读页可切换；搜索／格式筛选、目录、护眼、示例助手、引用定位、签到和手动计时沿用共享 demo。刷新重置，不写个人数据。导入、设置、另外两份资料及问答提交说明演示范围。手动计时不是番茄钟，示例回答不代表实际模型表现。

响应式继续沿用晴岛：1240px 以下助手变为浮层，900×640 保留顶部导航并滚动主区，760px 以下首页纵向，430px 以下资料和签到／计时单列。具体实际检查结果见 [VALIDATION.md](../VALIDATION.md)，不把预期行为当作已验证结论。

正式采用时只提取视觉与布局：`src/App.tsx` 负责顶部导航与首页结构，`RecentReadings.tsx`、`StudyCalendar.tsx`、`LibraryPage.tsx`、`ReadingPage.tsx` 保留真实数据和已有行为，样式归入 `src/styles.css`。以上为仓库根相对路径，完整角色见 `design.json.productIntegration`。数据仍走 `src/lib/desktop.ts`，保留真实错误、PDF 原页、引用和位置保存；不复制示例 HTML、回答或固定进度。
