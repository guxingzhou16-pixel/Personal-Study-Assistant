# 拾知 · Study Companion

**本地模型优先的 Windows 学习助手，让阅读、提问、笔记和下一次学习连在一起。**

拾知希望帮助你把“看过资料”推进到“能写出自己的理解”：读一份文档，带着问题核对原文，留下笔记，再把没弄懂的地方安排进下一次学习。

软件将 AI 辅助阅读与计划、专注、复习放在同一个工作台中。学习记录保存在本机，支持接入本地模型，也允许使用自己配置的云端接口；回应风格和界面主题可以按喜好调整。

## 下载与开始使用

当前可下载版本为 **0.1.1 预览版，面向 Windows 10/11 x64**。

1. 下载 [StudyCompanion-0.1.1-win-x64-setup.exe](https://github.com/guxingzhou16-pixel/Personal-Study-Assistant/releases/download/v0.1.1-preview.1/StudyCompanion-0.1.1-win-x64-setup.exe)。
2. 打开安装器，阅读并确认组件许可后安装。
3. 导入 PDF 或 Markdown，或从首页的学习示例开始。
4. 需要 AI 功能时，在设置中接入 Ollama 或兼容 OpenAI 的接口。

**普通用户无需下载源码 ZIP，也无需安装 Node.js、Git 或 C++ 编译工具，不需要注册软件账号。** Release 中的原生源码附件用于第三方开源许可与开发研究，校验清单用于核对下载文件。

本版尚未进行公众信任代码签名，Windows 可能提示未知发布者，部分设备策略可能阻止运行。请从本仓库 Release 获取软件；项目不要求关闭系统安全保护或导入自签根证书。

## 可以用它做什么？

| 能力           | 使用方式                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| 资料阅读       | 阅读 PDF 原页和排版后的 Markdown，使用目录、缩放、护眼模式及阅读位置恢复；选中原文即可提问或记笔记。 |
| 资料问答       | 从指定资料或资料库中检索片段，先预览依据，再生成回答；有效引用可跳回 PDF 页码或 Markdown 位置。      |
| 笔记与反馈     | 用结构化笔记整理自己的理解、依据、疑问与下一步；可请求 AI 辅助核对，并导出 Markdown。                |
| 学习路线       | 根据目标、可用时间和资料起草路线，核对步骤、引用和作品要求；选择步骤、预览并确认后安排任务。         |
| 卡片与轻量复习 | 按资料生成知识卡片或简答题，先回忆再看参考答案；选择保存作答、疑问和手动复习日期。                   |
| 计划与专注     | 管理学习项目和每日任务，使用任务关联番茄钟、签到、专注复盘与成果记录。                               |
| 本地管理       | 查看学习记忆和历史记录，选择主题与回应风格，并手动备份、恢复已保存的学习数据。                       |

任务和记忆的 AI 提议需要预览确认。专注时长、签到和任务完成分别记录，不会自动变成“已经掌握”的评价。

## 一次学习的流程

**确定目标 → 阅读资料 → 带着问题核对出处 → 写下自己的解释 → 专注练习 → 复盘与安排复习。**

例如，学习一份技术文档时，可以先阅读一个章节，再让助手检索相关解释；核对引用后写出自己的理解，把仍有疑问的部分保存下来，最后安排一项可以实际完成的练习。

即使暂时没有配置模型，也可以阅读资料、手写笔记、制定计划和使用专注工具。

## 本地模型与数据

聊天模型和检索模型承担不同工作：

| 模型               | 用途与准备                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| Ollama 聊天模型    | 用于生成回答、反馈和学习建议。Ollama 服务与模型由用户自行准备。                                            |
| 兼容 OpenAI 的接口 | 可自行填写服务地址、模型和密钥；账号及 API 费用由使用者承担。                                              |
| 本地 BGE 检索模型  | 可选下载约 23.3 MiB，用 CPU 将文本转为向量，辅助查找相关资料；它不负责聊天生成。未准备时仍保留关键词检索。 |

- 资料、笔记和学习记录默认保存在本机；首版没有账号系统或自动云同步。
- 选择远程模型并确认发送时，本次相关问题、资料片段或主动选用的内容会发送到你配置的服务；模型下载本身也需要网络。
- 本地语义检索需要可用的 Microsoft Visual C++ v14 x64 运行库；如果设置中提示缺少，请按官方入口安装或更新。运行库不等于 C++ 编译工具。
- 完整备份包含已保存的学习内容，未加密，不包含 API 密钥或模型文件，请妥善保存。

## 技术与项目方向

拾知同时是一个围绕真实学习场景持续迭代的 RAG 实践项目：

- **桌面与界面：** Electron、React、TypeScript。
- **阅读与存储：** PDF.js、安全 Markdown 渲染、SQLite。
- **本地 RAG：** FTS5 关键词检索、BGE 文本嵌入、ONNX Runtime CPU 推理与 RRF 混合排序。
- **证据与权限：** 检索原文预览、引用定位、用户确认后写入任务或记忆。
- **验证方式：** 核心测试、真实 Electron 流程、检索评测与有限真实模型复核。

引用能定位到原文，并不保证每句结论都正确；AI 回答、练习和建议仍需要结合资料判断。目前优先围绕真实使用反馈改善稳定性、阅读体验和 RAG 质量。

## 当前边界

- 当前提供 Windows x64 预览版，安装验证主要覆盖 Windows 11；其他机器上的体验仍需要反馈。
- 首版重点支持 Markdown 和可提取文字的 PDF。扫描 PDF 可查看原页，OCR 和更多文件格式留待后续。
- 暂无自动更新、自动云同步和完整间隔复习系统；更新通过 Release 手动下载。
- 普通聊天不会自动读取整个资料库；需要资料依据时，请使用资料问答或相应学习功能。
