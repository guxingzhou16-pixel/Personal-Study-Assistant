# 私人学习助手（Study Companion）

> **项目状态：产品规划中。** 当前仓库用于记录产品方向与后续开发；尚无可运行的软件。首发目标是 Windows 桌面应用，展示网站留到软件完成后建设。

私人学习助手是一款以本地数据和个人学习体验为中心的学习软件。它将资料阅读、可追溯的 AI 问答、学习笔记、计划和专注记录连在一起，帮助用户提升注意力和学习效率、理解知识、看见进步，并保持学习动力。第一版以编程与技术学习为主要场景，后续逐步扩展到跨学科资料。

## 核心学习流程（规划中）

**设定目标 → 阅读资料 → 提问求证 → 写出作品 → 获得反馈 → 复盘并安排下一步。**

用户为学习项目设定目标，将资料拆成每日任务；阅读时可以随时向 AI 提问，最终用结构化学习笔记表达自己的理解。助手依据资料给出反馈，并结合学习记录建议下一步。它默认以温柔陪伴的方式鼓励用户，也允许调整回应风格。

## 主要功能（规划中）

### 资料阅读

- 首版导入 PDF 和 Markdown。PDF 保留原始版式，提供目录、缩放、护眼、选中文本提问和引用跳转；Markdown 提供适合长时间阅读的排版。
- 阅读区搭配可收起的侧边助手和笔记区。首版优先处理可提取文字的 PDF；扫描件 OCR 和更多文件格式留待后续。

### 可追溯的 RAG 问答

- 从已导入资料中检索证据，再生成回答；引用定位到 PDF 页码或 Markdown 标题。资料不足时明确说明，不编造出处。
- 结合全文检索与本地向量检索，并通过固定问答集记录检索命中率、引用准确性和失败案例，让 RAG 效果可验证、可改进。

### 小型学习 Agent 与长期记忆

- 根据目标和资料建议学习步骤，辅助检索、解释、追问、起草笔记以及安排每日任务。
- 新增计划、更新进度或写入长期记忆前由用户确认。学习轨迹与个人偏好都可以查看、编辑和删除。
- 结构化学习笔记是默认作品。AI 给出有资料依据的已掌握点、知识缺口和改进建议；知识卡片与短测验按需生成。

### 模型接入

- 本地模型支持 Ollama；云端模型支持用户自行填写兼容 OpenAI API 的地址、密钥和模型名。本地与云端模型可平等选择。
- 资料检索所需的本地嵌入模型独立于聊天模型。用户无需因为选择云端聊天而安装 Ollama；嵌入模型不可用时保留关键词检索。
- 云端 API 费用由使用者自行承担，软件不内置收费模型服务。

### 计划、专注与个性化

- 以学习项目和每日任务组织计划；番茄钟关联任务，结束后支持简短复盘和打卡。
- 默认使用清爽现代界面，并提供安静书房、活泼游戏化主题；回应风格可在温柔陪伴、游戏化成长和高效教练之间切换。

## 数据与发布路线

首版仅支持 Windows，不要求账号或跨设备同步。资料、笔记、学习记录和偏好保存在本机，支持完整导出与导入；备份不包含 API 密钥。计划采用 React、TypeScript、Tauri、SQLite 和 PDF.js 实现桌面应用。

开发顺序为：资料阅读与本地保存 → 模型接入和引用问答 → Agent、笔记与记忆 → 计划、番茄钟、主题和备份 → 评测与 Windows 安装包。项目使用 Git 和 GitHub 仓库管理版本；软件完成后计划通过 GitHub Releases 发布。**展示网站最后建设**，只承担项目介绍和下载入口。
